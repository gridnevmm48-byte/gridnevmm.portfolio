# Maksim Gridnev — portfolio

Static portfolio site of a product designer. Live: https://www.gridnevdesign.com

- `index.html` — home page (desktop + app-like mobile mode, RU/EN)
- `cases/` — case studies: Respawn Esports, Queen Interactive Games, Pro Wrap
- `assets/` — images, covers, fonts

No build step: open `index.html` or serve the folder with any static server.
The previous React/Vite version is kept in the `backup/old-react-portfolio` branch.
